Personal Learning Workbench个人学习平台

JavaScript · Python · SQLite · Editable notebooks and local execution.

A personal learning workspace把课程、实验与工具放在一起

Plain JavaScript interfaces connect to a Python server, SQLite records and local programming runtimes. Editable notebooks, standard input and result panels support an example-first study workflow.

A standalone C stack example completed successfully and produced 8, 5, 2. Other modules include study notes, document/mistake tools, a mobile companion and backup/restore.

From deadlines to hands-on practice从考试作业安排，到知识学习与软件应用

Exam planning / 考试安排

Keep exam dates, times, locations, revision scope and permitted materials together, with course-source links and verification details.

Assignments and deadlines / 作业与截止时间

Group upcoming submissions and assessments into this week, next week and later. Display Sydney and Beijing times, record personal completion and keep unresolved dates visible for checking.

Knowledge maps and revision / 知识点与复习

Connect course and weekly notes through topic cards and searchable mind maps. Open explanations, examples and related experiments; track self-assessed mastery and revisit mistakes.

Editable programming practice / 编程练习

Edit code cells, provide standard input and run Python, Java, C/C++ or PHP locally. Read output and errors beside the example, then save changes for the next study session.

Learning software and resources / 学习软件与资源

Open relevant work in VS Code, Arduino IDE, Android Studio and Figma when installed. Keep course resources, document tools and practical project activities connected to the learning workflow.

Dates and requirements retain their course-source context. Personal progress checks are separate from official submission receipts.
