## [AI 辅助的交互式三维人物编辑系统](project-ai-nfc-character.md)



结合生成式 AI、NFC 实体卡片与交互装置，降低普通用户创作三维角色的门槛，并串联模型预览、编辑与打印。



**技术／工具：** Vue · Spring Boot · MySQL · Three.js · ESP32 · RC522 · Image generation · Hunyuan3D



## [React 活动管理系统](project-event-manager.md)



使用 React 组件与 Hooks 管理活动列表、搜索、日期排序和新增／编辑表单，通过 Axios 对接 REST API。



**技术／工具：** JavaScript · React · Vite · Axios · REST API · Express / MySQL integration



## [ESP8266 环境监测与远程控制原型](project-iot-monitor.md)



围绕 3D 打印耗材干燥场景，完成温湿度和光照采集、MQTT 消息传输及 LED／风扇控制的概念验证。



**技术／工具：** ESP8266 · Arduino C/C++ · DHT11 · LDR · MQTT · JSON · Python · Paho-MQTT



## [校园配送柜双端服务设计](project-right-locker.md)



从学生和配送员两端优化校园外卖取餐流程，通过柜体定位与编码验证减少找错柜、投错柜的问题。



**技术／工具：** Figma · User research · Storyboards · Information architecture · Mobile UI



## [智能健身产品与移动应用设计](project-smart-fitness.md)



把健身实体产品、移动端健康记录与品牌视觉整合为一套产品系统，覆盖运动、体重、饮食和社区等使用场景。



**技术／工具：** Figma · Product design · Mobile UI · 3D visualisation · Visual identity



## [光剑跳绳：游戏化健身交互概念](project-lightsaber-fitness.md)



将无绳跳绳动作映射为音乐跑酷中的挥剑、跳跃和攻击操作，通过即时反馈和多人积分机制提升参与感。



**技术／工具：** Interaction design · Motion-input mapping · Product modelling · Rendering



## [模块化 3D 打印小夜灯](project-modular-lamp.md)



通过 Rhino 建模、KeyShot 渲染及 3D 打印原型，探索可拆卸模块与外观自由组合的小夜灯设计。



**技术／工具：** Rhino · KeyShot · Modular design · 3D printing



## [PHP＋MySQL 联系人管理系统](project-php-contacts.md)



使用 PHP 与 MySQL 实现联系人列表、详情、新增、编辑和删除，练习表单处理、服务端页面与数据库交互。



**技术／工具：** PHP · MySQL · HTML · CSS · SQL · CRUD



每个项目页都配有对应图片和材料说明；原始设计稿、渲染图、源码排版图及概念方案均有区分。
