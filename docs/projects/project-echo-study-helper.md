# Echo Lecture Study Helper / 讲座学习助手

**JavaScript · Chrome Manifest V3 · DOM · Clipboard · AI-assisted learning**

A personal, AI-assisted extension prototype that reads an EchoVideo transcript and prepares translation, summary and question prompts for ChatGPT. The user copies and sends the prompt manually; it uses no OpenAI API key. / 读取讲稿并生成翻译、摘要和追问提示词的个人浏览器插件原型，由用户粘贴到 ChatGPT 发送。

[Browse source / 浏览源码](../../code/echo-study-helper) · [Download extension source / 下载插件源码](../../downloads/echo-study-helper-source.zip)

The archived version is 0.2.0. The source includes no lecture content or account data. JavaScript syntax and the extension manifest were checked; live EchoVideo compatibility was not retested during publication. / 本次检查语法和配置，未重新验证实时页面兼容性。
