# Modular Night Light

**模块化 3D 打印小夜灯**

A configurable night-light design built around interchangeable visual components.

通过 Rhino 建模、KeyShot 渲染及 3D 打印原型，探索可拆卸模块与外观自由组合的小夜灯设计。

**Tools & technologies:** Rhino · KeyShot · Modular design · 3D printing

## Design focus
Explore how interchangeable modules can let users personalise a small lighting product. The work combines exterior design, component modelling, product visualisation and a 3D-printing prototype workflow.
