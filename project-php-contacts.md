# PHP Contact Manager

**PHP＋MySQL 联系人管理系统**

A server-rendered contact-management application for practising forms and SQL CRUD.

使用 PHP 与 MySQL 实现联系人列表、详情、新增、编辑和删除，练习表单处理、服务端页面与数据库交互。

**Tools & technologies:** PHP · MySQL · HTML · CSS · SQL · CRUD

## Application workflow
Contact list → contact details → add or edit form → database update. A delete action completes the basic CRUD workflow.

The original project contains seven PHP files. The inspected version has no login page; this case study does not claim an authentication feature.
